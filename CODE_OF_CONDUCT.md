# Code of Conduct

## Purpose

This project is built and maintained in the open. This code sets a shared
baseline so contributors, users, and maintainers can collaborate without
friction. Participation in any project space implies agreement to follow it.

## Expected behavior

- Be direct and professional. Critique the work, never the person.
- Assume good intent and ask for clarification before escalating.
- Keep discussions focused. One concern per thread; stay on topic.
- Respect maintainers' time and decisions. A declined proposal is final
  unless new technical evidence justifies reopening it.
- Handle credentials, personal data, and customer information responsibly.
  Use synthetic values in examples, tests, and reports.

## Unacceptable behavior

- Harassment, insults, threats, or intimidation in any form.
- Discrimination based on personal characteristics or background.
- Sexualized language, imagery, or unwelcome attention.
- Publishing private information about others without consent.
- Sustained disruption, trolling, or bad-faith argumentation.
- Submitting knowingly false reports or abusing the reporting process.

## Reporting

Report conduct concerns through the repository host's private reporting
channel or by contacting the maintainers privately through the project
profile. Do not open a public issue for a conduct complaint.

Include what happened, where (links to issues, PRs, or comments), and when.
For security-sensitive matters, follow the private reporting guidance in
`SECURITY.md` where that file is present. Reports are handled
confidentially and acknowledged within five business days.

## Enforcement

- First violation: private warning with a clear statement of what must stop.
- Continued or serious violation: temporary ban from project spaces,
  including issues, pull requests, and discussions.
- Severe or repeated violation: permanent ban from the project.

Maintainers apply these steps at their discretion based on severity and
history. Enforcement decisions are final and are not debated in public
threads.

## Scope

This code applies to all project spaces: the repository, issue tracker,
pull requests, discussions, and any maintainer-organized communication
channels for the project.

## Attribution

This is a lightweight project code of conduct, written for this project
and informed by widely used open-source codes of conduct.
